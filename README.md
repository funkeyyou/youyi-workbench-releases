# 遊譯工坊

遊譯工坊是 Windows 上的遊戲翻譯與即時數值修改工具。

- **RPG Maker MV／MZ**：文字翻譯，以及物品、角色、變數、開關的即時修改和數值搜尋。
- **Unity（Mono／IL2CPP）**：數值搜尋、開關清單與「我的清單」，可以鎖定數值。

## 下載

到 [Releases](https://github.com/funkeyyou/youyi-workbench-releases/releases/latest) 下載最新的 `YouyiWorkbench-<版本>.exe`，放在可以寫入的資料夾（例如「文件」底下自己建的資料夾）直接執行，不必安裝。設定、API Key 與翻譯專案都存在 exe 旁邊的 `config`、`projects` 資料夾，搬移時整個資料夾一起搬。

程式沒有數位簽章，第一次執行時 Windows 可能顯示「Windows 已保護您的電腦」，按「其他資訊」再按「仍要執行」即可。每一版都附有 `SHA256SUMS.txt`，可以用 PowerShell 的 `Get-FileHash` 核對下載的檔案。

## 更新

工坊啟動後會自動檢查這個發佈頁。有新版本時，視窗右下角會出現綠色的「有新版本」，按下去可以看更新內容；按「立即更新」會下載新版並核對 SHA-256，完成後自動重新啟動、刪除舊版 exe，設定與翻譯專案都會保留。也可以從選單「說明 → 檢查更新」手動檢查。

## 翻譯服務

文字翻譯需要 API Key。**購買 API Key 額度請來信 funkeyyou@gmail.com**。拿到之後在「翻譯服務」分頁填入，工坊會自動列出可用的模型。只用即時數值修改的話不需要 API Key。

## 基本用法

1. 把遊戲執行檔、遊戲資料夾或捷徑拖進工坊視窗，或按工具列的資料夾圖示選擇遊戲；遊戲已經開著的話，按工具列最左邊的「選擇執行中的遊戲」。
2. 數值修改：在「遊戲內即時修改」按「安裝／更新面板」，再按工具列的播放鍵開始遊戲。右上角顯示「已連線」後，就能搜尋數值、切換開關；RPG Maker 遊戲另外可以在物品、角色、變數分頁直接修改。
3. 文字翻譯（RPG Maker）：在「文字與翻譯」按「翻譯全部」，或選取項目後按「翻譯選取項目」；完成後關閉遊戲，再按「套用至遊戲」。

修改前建議先在遊戲內存檔。工坊寫入遊戲檔案前都會先備份，可以在「備份與說明」還原；解除安裝面板時，放進遊戲的檔案也會一併移除。

## 系統需求

- Windows 10 或 11（64 位元）。
- RPG Maker MV／MZ：標準的 NW.js 版（有 `Game.exe`）。
- Unity：Windows 版遊戲，Mono 與 IL2CPP 都支援。第一次替 Unity 遊戲安裝面板時，工坊會從 BepInEx 官方發行頁下載載入器並核對 SHA-256。
